# paperless

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

行政手続きには、入力欄のない PDF を印刷して手書きし、封筒に入れて投函するしかないものが残っています。paperless は、様式の難しい欄を「会社を辞めましたか？」のような質問に置き換え、答えるだけで記入済みの PDF を作ります。できた書類はダウンロードするか、1 件ごとの支払いで郵送を頼めます。

> **開発中です。まだ使えません。** 下の内容は目指している形で、最初の様式は品川区の国民健康保険異動届です。

## Features

- **質問に答えるだけで書類が埋まる 📝**: 入力欄のない PDF でも、様式ごとの定義から作った平易なフォームで記入できます。
- **同じことを二度書かない 🔁**: 答えはアカウントではなく自分の端末に残り、次の様式で再利用できます。
- **印刷も投函もいらない 📮**: ダウンロードして自分で出すか、日本郵便への差し出しまで任せられます。

記入内容の確認と提出の判断は、利用者自身が行います。paperless が代理で提出することはありません。

## 開発

[mise](https://mise.jdx.dev/) でツールを入れて起動します。

```bash
mise install
bun install
bun run dev
```

`http://127.0.0.1:3000` が開けば成功です。
