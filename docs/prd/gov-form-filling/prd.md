# 行政の紙様式を質問に答えて仕上げる

> **保留中です。** 「未決の論点」に本人の回答が必要で、回答が出るまで実装には進みません。

## Problem

行政手続きには、入力欄のない PDF を印刷して手書きし、封筒で出すしかないものが残っている。専門用語の欄を読み解く手間と、印刷から投函までの物理的な手間が、手続きのたびに利用者にかかる。

## 導出

Story の「行政手続きの紙の書類を、平易な質問に答えるだけで書き上げて出せる」を、最初の 1 様式で成り立たせる。

## Overview

利用者は平易な質問に答え、記入された書類を確かめて、出すかどうかを自分で決める。できた書類はダウンロードするか、単発の支払いで郵送を頼む。答えは自分の端末に残り、次の様式で再利用できる。最初の様式は品川区の国民健康保険異動届で、対象とする手続きの範囲は未決とする。

### Goals

- 利用者が様式の用語を知らなくても、質問に答えるだけで記入済みの PDF を得られる
- 一度答えた内容を、次の様式で入力し直さずに済む

### Non-Goals

- 本人に代わって提出すること、個別の手続きについて助言すること
- 日本郵便以外の手段で書類を運ぶこと
- マイナンバーをサーバに渡すこと
- 品川区の国民健康保険異動届以外の様式

## Glossary

- **様式定義**: 様式ごとの欄の座標と意味。質問フォームと記入済み PDF は、ここから作る

## Domain Model

| 関係者 | 担うこと |
|---|---|
| 利用者 | 質問への回答、記入内容の最終確認、提出の意思表示 |
| paperless | 様式定義に基づく質問の提示と PDF の作成。郵送を頼まれた場合は日本郵便への差し出し |
| 日本郵便 | 配達 |

- 記入の答えはサーバに溜めず、利用者の端末に残す
- 利用者はログインして使い、郵送は単発の支払いで頼む。どの時点で求めるかは未決とする

## Acceptance Criteria

未決の論点に左右されない範囲だけを書く。

- 利用者が質問に答えると、答えが様式の正しい欄に入った PDF を得られる
- 利用者は PDF を出力する前に記入内容を確認できる
- 利用者が同じ端末で別の様式を使うと、答え済みの内容が再利用される
- サーバに記入の答えとマイナンバーが残らない

## 未決の論点

### 本人の回答が必要なもの

各論点の（推奨）は、事前調査を踏まえた候補で、合意したものではない。

1. **最初の PRD の範囲**
   - 作成とダウンロードを先に（推奨）: 質問からダウンロードまでを無料で出す。有料の郵送は次の PRD に回し、社労士法の確認と日本郵便の回答を入口条件にする。収益仮説の検証は後になる
   - 郵送まで 1 本で: 目的どおり郵送と決済まで書く。法律と日本郵便の確認が済むまで実装に入れない
   - 郵送の検証を先に: 課金が成り立つかを先に確かめる。有償になる時点で法律の確認が先に必要になる
2. **異動届で対象にする手続き**（様式は加入・脱退・変更・再交付を 1 枚で扱う）
   - 退職して国保に入る（推奨）: 質問の分岐と添付が少なく、将来 Webレターでも完結する
   - 加入と脱退: 対象は広がるが、脱退の原本同封は郵送代行で対応できない
   - 様式の全事由: 様式の定義としては自然だが、分岐と検証の範囲が増える
3. **マイナンバー欄の扱い**
   - 毎回入力して保存しない（推奨）: PDF の生成時だけブラウザで使う。入力の手間は毎回残る
   - 端末に保存して再利用: 二度書かずに済むが、端末からの漏えいリスクが残る
   - 空欄で出力して手書き: サービスは番号に触れない。印刷後に手書きが必要になる
4. **ログインを求める時点**（ダウンロードだけなら、サーバに置くものはほぼない）
   - 全員に必須: 現在の方針どおり。利用者数を測りやすく、郵送決済の土台になるが、入口で離脱されやすい
   - 有料郵送のときだけ: 入口が軽く、サーバの個人情報も増えない。AGENTS.md と README の変更が要る
   - 初回の範囲では入れない: 郵送を次に回す場合に限り選べる。最も小さく作れる

### 外部への確認が必要なもの

- **法律**: 国民健康保険法は社労士法の別表第一にあり、報酬を得た申請書の作成は社労士の業務に触れる可能性がある。2026-01-01 施行の行政書士法改正も報酬の名目を問わない。無料の作成と有料の郵送を組み合わせても安全とは言い切れないため、専門家に確認する。「記入の確実さ」への課金は、作成への対価に見えるので候補から外す方向で検討する
- **郵送**: 第三者のための差し出しが電子郵便約款で認められるかを日本郵便に確認する。公開 API は見つかっていない
- **区の受理**: マイナンバー欄が空欄の届出を受理するかを品川区に確認する

### 回答後に決めるもの

認証の方式（Void の auth は Better Auth を組み込んでいるので、候補の第一）、課金単位・価格・決済手段（Stripe Checkout など）、郵送時に PDF がサーバを通る区間の扱い。PDF の生成はブラウザを候補とする。pdf-lib で日本語を描くには fontkit と日本語フォントが要る。
